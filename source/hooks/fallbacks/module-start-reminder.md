## Open every module the same way

When the bootcamper accepts the start of a module, show the module-start orientation before
its first step, in the order "Module start banners and transitions" in `ground-rules.md` gives:
the banner, the journey map, the before and after, the step overview and the time estimate. The
setup modules that rule exempts stay exempt. Then work to the stage's working-depth instruction,
which the same section gives, without showing or mentioning it, and ask nothing about the model
or the reasoning effort.
