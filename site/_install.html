Checklist

Before you start

  • Network access to the SENZING® MCP server (https://mcp.senzing.com/mcp). The bootcamp cannot proceed without it. On a corporate network or VPN, ask for the domain mcp.senzing.com to be allowed.
  • A new, empty folder for the bootcamp.
  • Recommended A business problem and 5,000 to 20,000 records. A problem that needs entity resolution, and records that illustrate it. Recommended, not mandatory.

Install and start

Install the bootcamp and start it

After you start

What happens next

The bootcamp first asks you to choose your curriculum, level of detail and programming language, then guides you module by module. It is the same bootcamp in every assistant. See every module

When you graduate

What you finish with

  • Working Senzing code and data in your project (src/, data/, database/).
  • A professional recap PDF you can keep and share (docs/bootcamp_recap.pdf).
  • A write-up of what the Senzing SDK found in your data (docs/bootcamp_data_discoveries.md, also rendered as a PDF).
  • A production/ starter project.
  • Optional A narrated 2-minute graduation video (docs/bootcamp_recap.mp4). Graduation offers it once; say no and nothing is rendered.

Good to know

Tips

Bootcamp requests

Ask for any of these in plain English, at any time. {{host.site_commands_note}}

SayWhat it does
“Start the bootcamp”Start the bootcamp, or resume one already in progress.
“Bootcamp feedback”Share feedback about the bootcamp. Saved locally to docs/feedback/SENZING_BOOTCAMP_FEEDBACK.md, with the assistant you used recorded in each entry. Nothing is sent anywhere without your yes. To share it with Senzing, email the file to support@senzing.com.
“Make a note”Jot down an idea, question, reminder or to-do. Saved locally to docs/bootcamp_notes.md and folded into your recap at graduation.
“Graduate”Render the recap PDF and generate the production/ starter project. Graduation normally follows the last module on its own, so use this only to graduate early or to run it again.
“Back up the bootcamp”Package your bootcamp into a single zip under backups/packages/: either the results to share, or everything needed to continue on another machine.
