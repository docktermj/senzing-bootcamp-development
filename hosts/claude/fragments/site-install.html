Choose one path. Both end with the bootcamp running in Claude Code. In the Claude web app or a Claude IDE extension, see other Claude Code clients.

  • Claude Desktop (no terminal)
  • Claude Code CLI

Claude Desktop

Claude Code inside the desktop application. No terminal needed.

  1. Download and install Claude Desktop.
  2. Start Claude Desktop.

    If asked, install git.

  3. Open a new Claude Code session:
    1. In the left-hand pane, choose </> Code.
    2. In the Code pane, click New.
  4. Near the bottom, choose the working directory (it might say Select folder...), and select your new, empty folder for the bootcamp.
  5. Install the Senzing Bootcamp plugin:

    Note: These steps may change with the version of Claude Desktop.

    1. On the bottom, click the Add icon (+), then Plugins > Manage plugins.
    2. Select the Yours tab.
    3. In the upper-right of the Plugins pane, click Add > Add Marketplace. If the plus sign is missing, see Troubleshooting.
    4. In the Add marketplace pane, for URL:, enter: 
      https://github.com/Senzing/bootcamp
    5. Click Sync.
    6. To the right of Senzing bootcamp, click Add > install for project (personal).
    7. Close the Plugins dialog.
  6. On the bottom, set the mode, model and effort:
    1. Choose the Mode auto for a smooth ride.
    2. Choose the Model Opus 5.5.
    3. Choose the Effort medium.
  7. Near the bottom, in the agentic chat, enter: 
    Start the bootcamp

    Or enter /start-bootcamp. See Bootcamp requests for the rest.

Claude Code CLI

Claude Code in a terminal.

  1. Install the Claude Code CLI:

    macOS, Linux or WSL

    curl -fsSL https://claude.ai/install.sh | bash

    Windows, in PowerShell

    irm https://claude.ai/install.ps1 | iex

    Windows is fully supported. To work without a terminal, use Claude Desktop, which runs on Windows too.

  2. Add the Senzing Bootcamp marketplace: 
    claude plugin marketplace add Senzing/bootcamp
  3. Install the Senzing Bootcamp plugin: 
    claude plugin install senzing-bootcamp@senzing-bootcamp

    If the plugin is already installed, update it instead.

  4. Create a new directory for the bootcamp: 
    mkdir senzing-bootcamp
  5. Change into it: 
    cd senzing-bootcamp
  6. Start the Claude Code CLI on Opus 5.5 at medium effort, with --permission-mode auto for the smoothest ride: 
    claude --model claude-opus-5-5 --effort medium --permission-mode auto
  7. Start the bootcamp. Tell Claude: 
    Start the bootcamp

    Or enter /start-bootcamp. See Bootcamp requests for the rest.

The plugin works wherever Claude Code runs. Claude Code also runs in the Claude web app and in Claude IDE extensions (VS Code, JetBrains). The bootcamp supports those. This page has no verified install steps for them, so install the plugin the way your client installs plugins, then start the bootcamp.
