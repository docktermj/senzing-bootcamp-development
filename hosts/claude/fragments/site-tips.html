Model

One model is fine for the whole bootcamp. Opus 5.5 suits it well. The bootcamp never asks you to switch models or change settings along the way.

Update or uninstall

Update the plugin:

claude plugin update senzing-bootcamp@senzing-bootcamp

Uninstall the plugin:

claude plugin uninstall senzing-bootcamp@senzing-bootcamp

Remove the marketplace:

claude plugin marketplace remove senzing-bootcamp

Claude Desktop won’t take prompts, or the Add Marketplace + is missing

The Claude Desktop installation may be incomplete. Claude Desktop requires git: install git, then restart Claude Desktop.
