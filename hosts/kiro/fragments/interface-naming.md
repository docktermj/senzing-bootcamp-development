Whenever output, a question, or a doc tells the bootcamper to do something **in their Kiro
interface** — set a model, change reasoning effort, restart an MCP server, click a control — name
which interface. The bootcamp runs in one, and it has one name:

| Say | For |
| --- | --- |
| **the Kiro IDE** | The Kiro desktop application, where the bootcamp runs in the agentic chat. |

- **"Kiro" alone names the product, never an interface.** It is correct for things that are
  true of it everywhere — "the senzing MCP server configured in Kiro" — and wrong as a way of
  saying where a control is.
- **Vague is allowed only where the bootcamp genuinely cannot tell.** When the interface is
  undeterminable, "in your Kiro interface" is honest; it is never a shortcut for one you know.
