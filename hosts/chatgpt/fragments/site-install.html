The bootcamp runs in the Codex desktop app from OpenAI, not in the ChatGPT chat window.

  1. Download and install Codex from chatgpt.com/codex, then open the Codex desktop app.
  2. In the lower right of Codex, select the model:
    1. Choose the model {{host.model_capable}}.
  3. Create a project:
    1. In the left-hand navigation bar, to the right of Projects, click +.
    2. For the project name, enter Senzing Bootcamp.
    3. For the source folder, choose your new, empty folder.
    4. Click Create project.
  4. Install the plugin:

    Note: These steps may change with the version of Codex.

    1. In the left-hand navigation bar, click Plugins.
    2. In the upper right of the Plugins panel, click Add, then Add a marketplace.
    3. For Source, enter: 
      https://github.com/Senzing/bootcamp
    4. Click Add marketplace.
    5. Choose the Senzing marketplace, then click Senzing Bootcamp and Install plugin.
    6. Review and trust the plugin's lifecycle hooks when Codex asks. They run local Python commands that keep the bootcamp's files in your project.
  5. With the Senzing Bootcamp project selected, enter this in Codex’s agentic chat: 
    Start the bootcamp
