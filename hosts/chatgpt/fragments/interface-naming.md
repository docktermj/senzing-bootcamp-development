Whenever output, a question, or a doc tells the bootcamper to do something **in their ChatGPT
interface** — set a model, change reasoning effort, restart an MCP server, click a control — name
which interface. The bootcamp runs in more than one, and the names are not interchangeable:

| Say | For |
| --- | --- |
| **the Codex desktop app** | The desktop application. The bootcamp does not run in the ChatGPT chat window. |
| **the Codex CLI** | Codex in a terminal. |

- **"Codex" alone names the product, never an interface.** It is correct for things that are
  true of it everywhere — "the senzing MCP server configured in Codex" — and wrong as a way of
  saying where a control is.
- **Vague is allowed only where the bootcamp genuinely cannot tell.** When the interface is
  undeterminable, "in your ChatGPT interface" is honest; it is never a shortcut for one you know.
