The bootcamp runs in the Antigravity CLI, the successor to Gemini CLI.

  1. Install the Antigravity CLI and sign in.
  2. Download the Senzing Bootcamp: 
    git clone https://github.com/Senzing/bootcamp.git senzing-bootcamp-plugins
  3. Install the plugin from the download: 
    agy plugin install ./senzing-bootcamp-plugins/plugins/gemini/senzing-bootcamp
  4. Create a new directory for the bootcamp: 
    mkdir senzing-bootcamp
  5. Change into it: 
    cd senzing-bootcamp
  6. Start the Antigravity CLI: 
    agy
  7. Start the bootcamp. Enter: 
    Start the bootcamp
