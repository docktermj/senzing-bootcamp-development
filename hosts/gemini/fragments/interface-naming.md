Whenever output, a question, or a doc tells the bootcamper to do something **in their Gemini
interface** — restart an MCP server, click a control — name
which interface. The bootcamp runs in one, and it has one name:

| Say | For |
| --- | --- |
| **the Antigravity CLI** | Antigravity in a terminal, the successor to Gemini CLI. |

- **"Antigravity" alone names the product, never an interface.** It is correct for things that are
  true of it everywhere — "the senzing MCP server configured in Antigravity" — and wrong as a way of
  saying where a control is.
- **Vague is allowed only where the bootcamp genuinely cannot tell.** When the interface is
  undeterminable, "in your Gemini interface" is honest; it is never a shortcut for one you know.
