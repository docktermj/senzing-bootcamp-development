Choose one path. Both end with the bootcamp running in GitHub Copilot. This page has no steps for VS Code.

  • GitHub Copilot app (no terminal)
  • Copilot CLI

GitHub Copilot app

Graphical setup, from the app's Customize view.

  1. Get and install GitHub Copilot, open the app and sign in with your GitHub account.
  2. Add the marketplace:

    Note: These steps may change with the version of the GitHub Copilot app.

    1. In the left-hand navigation, select Customize.
    2. In the upper right, click + Add > Manage marketplaces...
    3. For Source, enter: 
      https://github.com/Senzing/bootcamp
    4. Click Add, then close the Manage marketplaces dialog.
  3. Install the plugin:
    1. In Customize, select the Browse tab and choose All types.
    2. Search for bootcamp.
    3. Select senzing-bootcamp and click Install.
  4. Start a session in your empty folder:
    1. In the left-hand navigation, select Sessions, then click New (+) > Add local folder or repository.
    2. Create or select a new, empty folder.
    3. In Mode, choose Interactive.
  5. In the agentic chat, enter: 
    Start the bootcamp

Copilot CLI

GitHub Copilot in a terminal.

  1. Install the GitHub Copilot CLI:

    macOS or Linux

    curl -fsSL https://gh.io/copilot-install | bash

    Windows, WinGet

    winget install GitHub.Copilot
  2. Add the Senzing Bootcamp marketplace: 
    copilot plugin marketplace add Senzing/bootcamp
  3. Install the Senzing Bootcamp plugin: 
    copilot plugin install senzing-bootcamp@senzing-bootcamp
  4. Create a new directory for the bootcamp: 
    mkdir senzing-bootcamp
  5. Change into it: 
    cd senzing-bootcamp
  6. Start the Copilot CLI: 
    copilot
  7. Start the bootcamp. Tell Copilot: 
    Start the bootcamp

GitHub Copilot also runs in VS Code, in its agent mode. The bootcamp has not been run in VS Code, and this page has no verified install steps for it.
